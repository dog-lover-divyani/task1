# 💼 CareerVault - Job & Recruitment Portal

CareerVault is a web-based job portal that connects job seekers with employers.  
It provides a platform for candidates to explore job opportunities and for recruiters to manage job postings and applications efficiently.

---

## 🌐 Live Demo

🔗 https://carrervault.xo.je/

---

## 🚀 Features

### 👤 Candidate
- Register and login
- Create and manage profile
- Upload resume and certificates
- Browse job listings
- Apply for jobs
- Save jobs for later

### 🏢 Employer
- Register and login
- Post job openings
- Manage job listings
- View applicants
- Download candidate resumes

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL

---

## ⚙️ How It Works

1. Users register as either candidate or employer
2. Employers post job listings
3. Candidates browse and apply for jobs
4. Applications are stored in the database
5. Employers review and download applicant details
